# Unform | 未形

An Agent for 3D Sketching and Creative Exploration.

一个围绕 Agent 的轻量 3D 草图 Demo：从体块、曲线和薄片开始，手动改形，让 Agent 延续动作，留下不同方向，再从旧版借回喜欢的局部。建模运行在浏览器中，Blender 是导出目的地。

## 本地启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

终端会显示工作台地址，默认 `http://127.0.0.1:5173`。前端端口被占用时 Vite 自动选下一端口；本机 Agent 服务使用 `4318`。关闭终端中的进程会同时停止两者。

## 先体验一轮

1. 打开卷叶灯，选择灯头，调整弯曲、扭转、收放，或者使用局部拉动工具横向拖动。
2. 输入“沿这个方向再夸张一点”，生成两个可编辑候选，留住喜欢的方向。
3. 回到旧版继续修改，点击“展开关系”查看父子分支；虚线表示局部借用来源。
4. 选择比较版本，打开“比较与借用”，在相同视角和尺度下查看两个版本，把来源部件复制到当前版本。
5. 画笔在正面 XY 工作平面绘制闭合轮廓，松手后生成薄片。新方向还提供小商店和抽象薄片示例。
6. 导出 GLB，可在 Blender 中导入；导出项目 JSON 可保留构造、版本、来源与最近动作，再导回继续编辑。

草稿自动保存到当前浏览器的 IndexedDB；切换浏览器、端口或清除站点数据后不会共享。项目导入前会自动下载当前项目备份。

## Agent 连接

默认的“本地规则预览”是明确标记的确定性规则，仅支持更夸张、舒展、更薄、克制和添加薄片。它用于体验工作流，不代表大模型理解或审美判断。

点击输入框右上的设置，填写支持 Chat Completions 和强制 function tool calling 的 API 地址、模型 ID、API Key。凭据只保存在本机服务进程内，重启后失效。启用配置不等于已通过服务商连接测试，实际调用失败会显示错误。

也可以将 `.env.example` 复制为 `.env` 后填写配置，重启服务。不要使用 `VITE_*` 储存凭据，不要提交 `.env`。

真实 Agent 接收当前场景、选中部件和最近四次动作的前后状态，返回 1–3 组结构化操作。浏览器校验参数、保持状态和实际几何；失败结果回传给模型，最多修复一轮。候选不会自动覆盖工作，基于旧版的迟到结果会成为分支。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `src/domain.ts` | DSL/schema、原子操作、版本提交、局部复制与导入校验 |
| `src/geometry.ts` | 截面体、曲线扫掠、轮廓拉伸与顶点形变 |
| `src/geometry.worker.ts` | Worker 构建、几何数组传输 |
| `src/Viewport.tsx` | Three.js 画布、绘制、选择、局部拖动与移动 |
| `src/App.tsx` | 创作工作台、候选、版本关系、比较和借用 |
| `src/ComparisonView.tsx` | 共享相机与尺度的双视图 |
| `src/scene.ts` | 场景、真实几何缩略图、GLB 导出 |
| `src/storage.ts` | IndexedDB 本地持久化，顺序保存 |
| `server/index.ts` | 本机凭据、模型工具调用和一次反馈修复 |

内部 DSL 是可执行 JSON 场景，包含构造、变换和形变参数。用户手动操作与模型操作共享该结构。Demo 没有实现任意网格快照、自由拓扑编辑、NURBS 编辑器或完整历史重放；每个版本保存独立场景快照，借用部件后可继续调整已有构造和参数。

“借回部件”复制为独立内容，替换时保留接收部件的位置；“借用形变”仅对原始构造完全相同的对象开放。不同拓扑之间不做自动语义匹配。保持部件会禁止形变、移动、换色及被替换。

当前形变包括沿局部 Y 的弯曲、扭转、收放，以及沿局部 X 的带衰减拉动。曲线来源可由 Agent 创建，但还没有手动曲线控制点编辑。轮廓生成面使用 Three.js 三角化；拉动预览与最终导出使用同一几何算法。

审美偏好学习、长期记忆、跨项目素材库、任意局部融合和 Blender 插件尚未实现。当前只把最近动作提供给本轮 Agent。GLB 保存实际网格与色块，不保留 Unform 的构造关系；继续在 Unform 编辑应使用项目 JSON。未检测自交、最小壁厚或可打印性。

## 验证

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

单元/接口测试覆盖保持约束、原子失败、迟到分支、局部独立性、不兼容迁移、导入引用、几何变化与法线方向，以及模拟模型的工具反馈修复。接口测试使用本机模拟服务，不消耗真实模型额度。

浏览器测试覆盖画布有效像素、视角变化、手动形变、保持、候选采纳、版本图、比较借用、GLB/项目导出、刷新持久化、轮廓绘制和手机布局。截图位于忽略提交的 `test-results/`。
